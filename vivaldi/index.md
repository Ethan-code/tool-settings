# vivaldi

Vivaldi 沒有內建匯出／匯入設定，換機器時照這份手動重做。

## 介面

1. Settings → Appearance
    - Layout：選 **Simple**
    - UI Auto-Hide，勾選 Enable UI Auto-hide，子項只勾 Tab Bar
2. Settings → Tabs → Tab Bar Position：選 **Left**
3. Settings → Bookmarks：取消勾選 Show Bookmark Bar
4. 如果右側有 Panel，按 `F4` 關閉

## 預期
- 移到瀏覽器視窗左方，會浮出分頁列
